# 功能清单与决策记录

日期：2026-10-20  
用途：重构前的功能盘点。每行给出 ID，便于逐条给指示。  
处置含义：**保留** = 语义不变；**重做** = 功能保留、实现替换；**删除** = 建议砍掉；**待定** = 需要产品决策。

> 原则：这里只记录“要什么功能”，不沿用旧实现的解决问题方式。旧实现中的绕路与补丁另见 `patch-audit.md`。

## 0. 已确定的决策

| ID | 决策 | 影响 |
| --- | --- | --- |
| D-01 | Cloudflare 使用 **Free 套餐** | Worker 每请求 10ms CPU；Durable Object 每请求 30s。**DO 必须保留**，但只承接解析/校验等 CPU 密集路径；删除正则分发器，由 Hono 显式路由 |
| D-02 | `visibility` 只有 **public / private** 两态，不设 unlisted | 旧 `visibility=0` 迁移为 private；private 项目对非作者/审核者返回 404，文件同样不可取 |
| D-03 | **匿名不可见完整内容** | 公开详情只返回摘要与条目索引；manifest 与可安装文件需要登录 + 权限检查 |
| D-04 | **订阅计数保持公开** | 列表与详情继续返回 `subscribesCount` |
| D-05 | 功能范围基本不变 | 不借重构删除抽签、私人评分、修复、精选等能力 |
| D-06 | UI 后续用 React + Tailwind + shadcn + Vite 专项重做 | 本轮只定义 API/静态资源边界 |
