# 开场动画后的页面氛围底图层（暂定方案一）

- **Status**: `proposed`（暂定方案一，等待用户提供/选定底图素材后再进入实现）
- **Owner**: Frontend (`apps/worker/web/src/styles/base.css`, `apps/worker/web/public/`)
- **Related**: [`../implemented/new-ui-visual-direction.md`](../implemented/new-ui-visual-direction.md)

## 问题与背景

当前开场动画（`apps/worker/web/src/components/IntroSplash.tsx`）采用四色流体颜料（纯黑 `#000000`、薄荷青 `#6FCEC8`、朱砂暖橙 `#FF3B1D`、明黄 `#FFD43B`），视觉情绪饱满；但在动画退场后，主页底色（`apps/worker/web/src/styles/base.css`）直接回落到接近纯深灰的 `#111318`（仅顶部有 `0.1` / `0.05` 透明度的两道径向渐变），整体略显沉闷且与开场动画存在情绪落差。

## 暂定方案（方案一：预模糊彩色底图氛围层）

在页面最底层叠加一张带有色彩层次的背景图（由用户后续提供或选定与《命定之诗与黄昏之歌》调性契合的素材），替代单一深色纯底：

1. **离线预模糊与轻量压缩**：在入库前将底图预先做高斯模糊并导出为轻量 WebP（目标约 25–45 KB），避免在浏览器中对全屏大图执行实时 CSS `filter: blur()` 带来不必要的 GPU 重绘开销。
2. **固定底层与暗角压暗**：使用独立固定层（`position: fixed; inset: 0; z-index: -1; pointer-events: none`）承载底图，控制不透明度在约 `12%–22%`，其上叠加深色暗角/线性遮罩，确保卡片与正文对比度满足深色阅读舒适度。
3. **半透明表面承接**：顶栏、筛选条及卡片表面可保持轻微半透明或柔和毛玻璃，让底层色温隐约透出而不抢封面图主体。
4. **可访问性与降级**：在 `prefers-reduced-transparency` 或图片加载失败时平滑回退到现有 `--bg` 深色底与渐变。

## 评估过的其他备选方案

- **方案二（纯 CSS 四色弥散光斑 + 微噪点）**：提取开场四色做大半径柔光色块并叠加 SVG 胶片噪点防色带。零图片体积，但画面感不如实图丰富。
- **方案三（发现栏封面色全局氛围溢出）**：将 `.discovery-tint` 外溢至整页上半区随选中作品动态变色。动态感强，但受单张封面色彩质量波动影响较大。
- **方案四（开场 WebGL 尾帧墨流残影定格）**：保留退场后的柔焦彩色墨流作为静态底纹。叙事衔接最强，但需额外控制纹理清晰度以免干扰卡片浏览。
- **方案五（微材质噪点 + 顶栏渐变光丝 + 卡片微光边）**：极克制的材质增强方案，适合未来按需作为“质感层”叠加在方案一之上。

## 影响与风险

- **对比度风险**：底图过亮或局部高饱和会降低暗色模式下次级文字（`--muted` / `--dim`）可读性，实现时需以深色暗角遮罩兜底并实测卡片与列表可读性。
- **性能风险**：若直接使用大图配合实时大半径 `filter: blur()`，在 2K/4K 滚动时可能触发掉帧；必须采用离线预模糊小图 + `position: fixed` 独立层。
- **静态资源体积**：需确保最终 WebP 尺寸克制，且不影响首屏 LCP。

## 后续验证要求（实现阶段）

- 在 2K（2048px / 2560px）、1440px 与移动端视口截图验证暗色对比度、卡片层次与滚动流畅度。
- 验证底图加载前/失败时无白屏闪烁，且 `pnpm check` 与构建产物通过。
